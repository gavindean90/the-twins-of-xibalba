# Editorial workbench (proposed V2)

This directory contains **proposals for author review**, not amendments to the seven published books.

- [PROJECT_CHARTER.md](PROJECT_CHARTER.md) — scope, source fidelity, form, creative license, bounded workflow and unresolved artistic decisions.
- [XIBALBA_EPISODES.md](XIBALBA_EPISODES.md) — 45 stable editorial beats, grouped into five movements and linked to existing corpus event/passage IDs with evidence grades.

## Working rule

Read only the charter, the relevant portion of the episode register, the linked corpus dossier and a short span of neighboring accepted verse during an individual drafting session. Store accepted decisions and finished episode revisions in versioned files rather than relying on chat context.

The first implementation step is **reviewing scope and weighting these beats**, then auditing the existing stanzas before drafting. The chapter/book count remains open.

The authoritative research material remains in [the corpus](../corpus/README.md). This directory does not replace source documents or alter their rights status.

**Preservation:** `book-1.md` through `book-7.md`, their HTML versions and existing artwork remain the published V1. Do not rewrite them as part of editorial planning.
